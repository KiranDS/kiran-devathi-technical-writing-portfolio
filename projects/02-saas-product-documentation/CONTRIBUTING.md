# Contributing to the SupportFlow documentation sample

This repository is a technical-writing portfolio project. Contributions should preserve its fictional-product disclosure and editorial standards.

## Before editing

1. Read the project [README](README.md).
2. Review [Terminology and editorial standards](assets/terminology.md).
3. Check the [Glossary](docs/glossary.md) before introducing a product term.
4. Keep examples fictional and free of personal or confidential data.

## Content review

Before committing:
- Validate Markdown headings and tables.
- Check relative links.
- Confirm that procedures have prerequisites and expected results where useful.
- Check terminology consistency.
- Identify assumptions and illustrative behaviour explicitly.
- Do not add unsupported security, privacy, compliance, or performance claims.

## Suggested commit-message format

Use concise, action-oriented messages, for example:
- `Add administrator guide`
- `Clarify ticket status definitions`
- `Update SLA examples`
- `Fix documentation navigation links`
