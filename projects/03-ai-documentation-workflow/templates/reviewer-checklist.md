## Source and factual checks
- [ ] Each claim has a source ID.
- [ ] Each source is approved.
- [ ] No fact has been inferred.
- [ ] Dates, limits, permissions, plans, and availability match the source.
- [ ] Limitations and prerequisites are preserved.

## Content checks
- [ ] All approved customer-facing changes are included.
- [ ] Pending and rejected changes are excluded.
- [ ] Internal-only notes are excluded.
- [ ] Audience and terminology are appropriate.

## Risk and approval
- [ ] No restricted data is present.
- [ ] Specialist review completed if required.
- [ ] Critical findings = 0.
- [ ] Major findings = 0.
- [ ] Product approval recorded.
