# Contributing

This is a fictional portfolio demonstration. Contributions should preserve the distinction between source facts, AI-generated draft content, and human-approved content.

## Contribution rules

1. Do not add confidential, proprietary, customer, or employer-derived material.
2. Use fictional product names, identifiers, dates, and data.
3. Every customer-facing claim must be traceable to a source record.
4. Mark unsupported information as `NEEDS CONFIRMATION`; do not infer it.
5. Do not describe illustrative metrics as measured production results.
6. Update the traceability matrix and QA checklist when examples change.
7. Keep the human approval requirement explicit.

## Suggested review

- Check factual accuracy against the source records.
- Check terminology, audience, style, and accessibility.
- Check that limitations and prerequisites are not omitted.
- Check that no secrets, personal data, or internal implementation details are exposed.
